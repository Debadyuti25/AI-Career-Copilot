# AI Career Copilot 🚀

An intelligent web application built with Flask and Python that acts as your personal AI career coach. It helps you analyze resumes, check career roadmaps, and provides smart AI-driven guidance for your professional growth.

## 🛠️ Tech Stack
* **Backend:** Python, Flask, SQLAlchemy
* **Frontend:** HTML5, CSS3, Jinja Templates
* **Database:** SQLite
* **AI/Parsing:** Custom Python modules for resume and career analysis (`ai.py`)

## ✨ Features
* User Signup / Login with session management
* Resume Upload (PDF / DOCX) and AI-based analysis
* Personalized Career Roadmap generation
* Learning resources and progress tracking
* Dashboard with history

## 📂 Project Structure
* `app.py` - Main Flask application routes and core logic
* `models.py` - Database models and schema definitions
* `ai.py` - AI integration and resume analysis logic
* `db.py` - Database connection handler
* `templates/` - HTML templates (Dashboard, Login, Signup, Roadmaps)
* `static/` - Stylesheets and static assets (`style.css`)
