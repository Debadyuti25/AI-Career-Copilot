# AI Career Copilot 🚀

An intelligent web application built with Flask and Python that acts as your personal AI career coach. It helps you analyze resumes, check career roadmaps, and provides smart AI-driven guidance for your professional growth.

* **Backend:** Python, Flask, SQLAlchemy[span_0](start_span)[span_0](end_span)
* **Frontend:** HTML5, CSS3, Jinja Templates[span_1](start_span)[span_1](end_span)
* **Database:** SQLite[span_2](start_span)[span_2](end_span)
* **AI/Parsing:** Custom python modules for resume and career analysis (`ai.py`)[span_3](start_span)[span_3](end_span)
